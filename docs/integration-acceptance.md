## 接受条件

1. 人工分别决定两个功能 PR 是否合入集成分支，记录批准的 head SHA。
2. 接受的功能合并后安装 `.[yaml,mcp]`，运行全部测试。
3. 在同一数据库上用模块／YAML 写入问题与粒度，再通过 MCP 读取历史或生成计划；反向亦可。
4. 验证记录没有遗漏已传入的消息，人工改动使旧计划失效。
   另外验证非数目型参数、各模块／方向独立设置、用户询问、项目默认与模块覆盖优先级，以及默认变化使使用它的旧计划失效。
5. 更新本文件与集成 PR 的最终范围和测试证据，再请求集成 → 框架的人工审批。
